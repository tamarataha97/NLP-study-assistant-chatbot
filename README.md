\# NLP Study Assistant Chatbot



This project is a simple NLP study assistant chatbot built with Python.



It answers beginner-level questions about Natural Language Processing and Semantic Technologies. The chatbot uses TF-IDF and cosine similarity to match a user's question with the most similar question in a small FAQ dataset.



\## Features



\- Loads questions and answers from a CSV file

\- Uses TF-IDF vectorization

\- Uses cosine similarity to find the closest question

\- Returns an answer based on the best match

\- Handles unknown questions with a default response



\## Example Questions



\- What is NLP?

\- What is tokenization?

\- What is sentiment analysis?

\- What is BERT?

\- What is RDF?

\- What is Apache Jena?

\- What is SPARQL?



\## Technologies Used



\- Python

\- pandas

\- scikit-learn

\- TF-IDF

\- Cosine similarity
